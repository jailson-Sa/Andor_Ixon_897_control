# Andor iXon 897 Control — Professional Scientific Acquisition GUI

This repository contains a Python control and acquisition software stack for an **Andor iXon 897 EMCCD** using the **Andor SDK2 / ATMCD DLL**.

The project does **not** bundle proprietary Andor DLLs. Install the Andor Driver Pack / Solis / SDK2 separately and pass the path to `atmcd64d.dll` when launching the software.

This repository was initialized from the current project milestone. The remaining package files will be added in the next commit.
